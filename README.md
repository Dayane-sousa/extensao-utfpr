#sobre: CURSO DE PROGRAMAÇÃO WEB - 200 HORAS

O Curso de Programação Web é uma formação gratuita e on-line voltada para iniciantes, estudantes, profissionais e demais interessados em tecnologia, desenvolvimento de sistemas e criação de aplicações para internet. O curso busca proporcionar uma formação prática e acessível, abordando desde os fundamentos da programação até o desenvolvimento de aplicações web modernas, responsivas e interativas, contribuindo para a formação tecnológica e digital dos participantes.

Conteúdos abordados:
✔ História da Programação Web
✔ Fundamentos da Programação Web
✔ Lógica de Programação
✔ HTML5 e CSS3
✔ Fundamentos de Java
✔ Integração Web com Java
✔ Banco de Dados e SQL
✔ Projeto Prático de Desenvolvimento Web
